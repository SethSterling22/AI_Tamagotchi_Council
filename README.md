# AI Council

Consejo de mascotas pixel-art, cada una un modelo pequeño en su propio dispositivo, coordinadas por un lobby web.

```bash
pip install -r server/requirements.txt pytest playwright
make test && make dev      # http://localhost:8080
```

Empieza por **`docs/estado.md`** (estado, mediciones, decisiones, preguntas abiertas) y **`CLAUDE.md`** (reglas para trabajar el código). Hitos en `docs/hitos.md`.
